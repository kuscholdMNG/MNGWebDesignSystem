MNG icon font

Organized like the Figma "Icon Categories" page (MNG Web Design System, 1412:13). Every icon is named by its production class. Glyphs are the production icomoon font, the same on every MNG site. Under each name: IcoMoon: name = original IcoMoon artwork and its name in IcoMoon; Custom = MNG artwork. Badges: wrong glyph = production class shows the wrong icon, no class = glyph exists but production has no class, new artwork pending = replaced in the next font build. Hover a tile for the note.
