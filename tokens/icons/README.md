The production `icomoon` icon font, organized like the Figma **Icon Categories** frame (MNG Web Design System › Icons | 2026.08.28, node `1412:13`). **All MNG sites use the same icon font** (Karl, 2026-10-08). Differences in production are in `design-vs-production.md` entry 1.

## Files

| File | What it is |
|---|---|
| `icomoon.ttf` | The exact production font (32,944 bytes), from the `@font-face` in ocregister.com's `boldcoastal.css` |
| `icomoon.woff`, `icomoon.woff2` | Web versions converted from the TTF with fontTools (same glyphs) |
| `icons.json` | The source for everything else here: category, production name and class, artwork source, IcoMoon name, description, codepoint, Figma node and status for 171 icons; the next font build; production-only classes |
| `icomoon.css` | `@font-face` plus one class per icon, named by its production class. Generated from `icons.json` |
| `preview.html` | Every icon by category with its production class, IcoMoon name or "Custom", and status, plus the next font build. Generated from `icons.json` |
| `preview.png` | Every glyph actually in the production font, by codepoint (174) |
| `svg-missing/` | Artwork for the next font build: the 17 icons to add and the new `notification` / `notification2` artwork |

To change a name, description or status, edit `icons.json`, then run `python3 scripts/icon-font/build.py` from the repo root.

## Names and artwork sources

- **Name:** the production class, without `icon-` (for example `hamburger`, `home3`, `enlarge`, `music5`). Two icons have no production class yet (`content_copy`, `ios_share`), so they keep their Figma names.
- **`artworkSource: "icomoon"`** (146 icons): original IcoMoon artwork. `icomoonName` is the name to search for in IcoMoon. It differs from the production name for 9 icons: `hamburger` (IcoMoon `menu7`), `enlarge` (`enlarge7`), `enlarge2` (`enlarge`), `shrink2` (`shrink`), `user4` (`users`), `heart-broken2` (`heart-broken`), `book3` (`book`), `quill3` and `quill4` (`quill`).
- **`artworkSource: "custom"`** (25 icons): MNG artwork, made in-house or changed from an IcoMoon icon (the blue names on the Figma page), plus the four-color Google mark, which was imported from an SVG.

The IcoMoon names come from the MNG IcoMoon project (`selection.json`, 2025-03-19, Google Drive › Icons › MNG IconFont Update 20250319). Where the project had renamed an icon, the icon's IcoMoon tag gives the original name.

## Status of the 171 icons in production

- **166 match**: the production class has this name and glyph.
- **3 production classes show the wrong glyph** (the right glyph is in the font): `grid2` → U+E932, `windows8` → U+E987, `book3` → U+E993.
- **2 have no production class** (the glyph is in the font): `content_copy` → U+E921, `ios_share` → U+E93A.

## Not included

- Third-party vendor icons (cookies, weather, commenting) and the "Need to source/make/add" list (Obituary, Funeral Home, Find Your School): out of scope for this package.
- Payment marks (Visa, AmEx, Apple Pay…): kept out of the icon font on purpose (see `components/icons.md`).
- Production-only classes with no Figma entry: `icon-google-plus` (no glyph), `icon-mng-podcast1` (duplicate of android), `icon-users4` (duplicate of user4). Listed in `icons.json`.

## How it was made

The TTF was saved from the live OC Register page in Chrome (ocregister.com can't be fetched directly from Claude's sessions). Production class → codepoint pairs come from the theme CSS (`.icon-X::before { content: var(--icon-X) }`). Every Figma icon was rendered next to its production glyph to confirm the match. More history: `components/icons.md`.
